Скрипт написан ГПТшкой, решает задачу обновления сертификатов шифрования под рэд виртуализацию, в данном случае под версию 7.3, но возможно так же отработает на похожих системах виртуализации основаных на oVirt
Проблема возникает, если продинамить сроки обновления сертификатов, в следствии, интерфейс становится недоступен, и\или заваливаются сервисы libvirt и wdsm
